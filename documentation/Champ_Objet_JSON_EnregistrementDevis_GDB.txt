1) Rôle: Enregistrer un devis Globale De Banque (créer un nouveau devis ou modifier un devis existant)

2) URI: api/enregistrementdevisglobaledebanque

3) Méthode: POST

4) Objet JSON:
IdIntermediaire,
IdCompagnie,
IdProduit,
IdAvenant,
IdClient,
IdAssure,
Flotte,
Coassurance,
DateEffet,
DateExpiration,
DateEmission,
IdTarif,
TauxPrime,
TauxReduction,
CapitalDetournementUsageFaux
CapitalDommagesConfondus
CapitalDeteriorationImmobiliere
MontantPrime
IdDevis
IdDuree
TelephoneAssure

5) Règles d'utilisation:
	a) Le champ IdDevis est égal à zéro à la création du devis. Pour la modification d'un devis, IdDevis prend la valeur de l'identifiant du devis en cours de modification
	b) Le champ Flotte est égal à False
	c) Le champ Coassurance est égal à False

6) Exemple d'objet JSON:
{'IdIntermediaire': 1, 'IdCompagnie': 14, 'IdProduit': 9, 'IdAvenant': 1, 'IdClient': 35, 'IdAssure': 35, 'Flotte': False, 'Coassurance': False, 'DateEffet': '09-07-2023', 'DateExpiration': '09-07-2023', 'DateEmission': '09-07-2023', 'IdTarif': 83, 'TauxPrime': 10, 'TauxReduction': 5, 'CapitalDetournementUsageFaux': 10000000, 'CapitalDommagesConfondus': 100000, 'CapitalDeteriorationImmobiliere': 100000, 'MontantPrime': 52000, 'IdDuree': 4, 'TelephoneAssure': '0102050406', 'IdDevis': 0
}
